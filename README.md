## What I Built & Learned

Working through 14 parts of structured exercises, building real programs at each stage:

- **Core Java** — variables, control flow, methods, arrays
- **Object-oriented programming** — classes, encapsulation, inheritance, interfaces, polymorphism
- **Data structures** — ArrayLists, HashMaps, implementing linked lists and hash tables from scratch
- **Algorithms** — linear search, binary search, selection sort
- **Functional Java** — lambdas, streams, list processing
- **File handling** — reading and writing files, parsing CSV data
- **Generics** — type parameters, building generic data structures
- **UI** — Swing, JavaFX, data visualisation
